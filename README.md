# Elevate Horizon Connect

## Author
[Judah Paton]

## Project Purpose
Elevate Horizon Connect is a cross-platform mobile application built for a local council group to strengthen community ties. It replaces manual spreadsheet and email event tracking with an accessible digital MVP that allows local residents to easily discover, filter, and register for upcoming community programs and events.

## Core Features
* View a dynamic list of Today's Events and all upcoming community events.
* Search and filter events by keyword or date.
* View comprehensive Event Details and submit registrations via an interactive form.
* Customize accessibility and app preferences in Settings (adjustable font sizes, Light/Dark themes, and sound toggles).
* Responsive layout supporting mobile portrait and tablet landscape orientations with built-in loading and error states.

## Tech Stack
* React Native (Expo)
* React Native Paper
* JavaScript / ES6+ (`fetch` API with `async/await`)
* Git & GitHub
